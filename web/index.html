Credentials
How do I get short-term credentials?

Run one of these with the AWS CLI and paste its output above.

IAM user keys (MFA optional):

aws sts get-session-token --duration-seconds 3600

A role (recommended: a role scoped to the tables you intend to use):

aws sts assume-role --role-arn <scoped-role> --role-session-name ddbsh-web

An IAM Identity Center (SSO) profile:

aws sso login --profile <p> && aws configure export-credentials --profile <p> --format env

Recommended: a role scoped to the tables you intend to use. Long-term AKIA… keys are refused. Credentials stay in this tab's memory and are gone on reload.
