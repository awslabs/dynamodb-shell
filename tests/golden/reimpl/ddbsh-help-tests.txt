# ddbsh-help-tests.txt — golden-parity family for the HELP command (phase 2i,
# AI-2i-B). The original ddbsh never golden-tested HELP; these goldens were
# RECORDED FROM THE ORIGINAL ddbsh (`ddbshtest -R`, oracle build) and are
# reproduced byte-for-byte by the reimplementation (D-2i-2: the oracle is the
# golden source). HELP output is fully deterministic and version-independent
# (the usage strings carry no version), so no sort (-s) is used.
#
# One test per HELP command FORM (D-2i-3: each whole-command form is a distinct
# command and is covered separately). The grammar's help_command production has
# 28 forms (general + 27 topics); all 28 are covered here.
#
# ${RD_REIMPL} is the reimplementation-owned golden results dir
# (tests/golden/reimpl/results), set by tests/golden/CMakeLists.txt. It is kept
# separate from the relocated original-suite results dir (${RD}, under
# tests/golden/suite/results) so the two trees stay cleanly separated.
